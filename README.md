# The Ending of Mark

[Open the exhibition on GitHub Pages](https://nericson.github.io/ending-of-mark/)

An interactive exhibition on the textual history of Mark 16. Compare manuscript facsimiles, read the competing endings in Greek and English, and test the vocabulary argument against other passages in Mark. The exhibition includes a research report, a reproducible vocabulary analysis, and links to primary sources.

## Hosting

The repository root is the website. For GitHub Pages, select **Deploy from a branch**, then **main** and **/ (root)** under **Settings → Pages**. The site uses relative URLs and carries its own fonts, images, JavaScript, and stylesheets.

## Local preview

Run `python3 -m http.server 8000` from this directory and visit `http://localhost:8000/`.

## Sources and credits

The exhibition’s Sources section identifies the manuscript collections, editions, facsimiles, and their credits. Font licenses are included in `assets/`.
